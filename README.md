# DEAD ISLAND — website

Static landing page and compiled Windows player download. This repository contains no Godot project, game source scripts, OAuth secrets or server databases.

Render Static Site settings:

- Build command: `python build.py`
- Publish directory: `public`
- Optional environment variable: `SITE_URL` with the final HTTPS site URL.

The download button reconstructs the verified Windows ZIP from three static parts. Screenshots are real frames from the current game.
